🌌 Planets Fact Site

An 8-page fact site showcasing detailed information about all the planets in our solar system. Each planet page contains:

✅ Overview
✅ Internal Structure
✅ Surface Geology
✅ Rotation & Revolution Time
✅ Radius & Average Temperature

✨ Features
🪐 8 separate pages – one for each planet

📊 Tabbed sections for switching between details

🔄 Easy planet navigation via the top menu

📱 Responsive design for all screen sizes

✅ Accurate facts with Wikipedia as a source

🛠️ Tech Stack
HTML5 – Structure

CSS3 – Styling & Layout

JavaScript (Vanilla) – Tab interactivity

📚 Sources
Wikipedia

NASA official resources
